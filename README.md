# VVB — Play. Collect. Earn.

VibeVibe reward & game interface on Robinhood Chain testnet.

## Features
- Hero landing with live (or demo) on-chain stats
- Floating Viber characters
- Mystery Boxes
- Missions
- Game arena preview
- Sound effects on interactions

## Run locally
```bash
pnpm install
pnpm dev
```

Open http://localhost:5173

## Deploy
Connect the repo to Vercel and deploy.
